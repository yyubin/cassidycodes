# cassidycodes

개인 개발 블로그

## 기술 스택

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS 4
- **Comments**: Giscus (GitHub Discussions)
- **Content**: Markdown (react-markdown)
- **Syntax Highlighting**: react-syntax-highlighter
- **Math**: KaTeX

## 주요 기능

- 📝 **Articles**: 심층 기술 글
- 💡 **TIL**: Today I Learned 학습 노트
- 🤔 **Reflections**: 프로젝트 회고
- 💬 **Misc**: 잡담 글
- 🔍 **검색**: 제목, 태그 기반 검색
- 🏷️ **태그**: 태그별 포스트 필터링
- 💬 **댓글**: 포스트별 Giscus 댓글 시스템
- 🌙 **다크모드**: 시스템 설정 연동
